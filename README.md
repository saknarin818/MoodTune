# MoodTune
MoodTune เป็นแอปพลิเคชันที่ช่วยสร้างเพลย์ลิสต์เพลงตามอารมณ์และสภาพอากาศในปัจจุบัน โดยใช้ API ข้อมูลจากบริการพยากรณ์อากาศและ Spotify API เพื่อวิเคราะห์และจับคู่เพลงที่เหมาะสมกับบรรยากาศ ณ ขณะนั้น

🎵 ฟีเจอร์หลักของ MoodTune
จับคู่เพลงตามสภาพอากาศ: เมื่อฝนตก แอปจะแนะนำเพลงแนวอะคูสติกหรือแจ๊สที่ช่วยให้คุณรู้สึกผ่อนคลาย ในวันที่แดดจ้า เพลงแนวพอปหรืออิเล็กทรอนิกส์จะแสดงขึ้นมาเพื่อเสริมพลังบวกให้กับวันของคุณ
เพลย์ลิสต์ตามอารมณ์: หากคุณรู้สึกมีความสุข เศร้า หรืออยากได้แรงบันดาลใจ สามารถเลือกอารมณ์ปัจจุบัน แล้ว MoodTune จะสร้างเพลย์ลิสต์ที่เหมาะสมกับอารมณ์ของคุณ
